**Project:** Titanic Survival Exploration
T**ools Used:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

**📌 Project Overview**
This project performs Exploratory Data Analysis (EDA) on the famous Titanic dataset.
The goal is to understand the factors that influenced passenger survival, including:

-Passenger class
-Gender
-Age
-Fare
-Embarkation port

The analysis includes data cleaning, visualizations, and insights.

## 🔍 Key Insights

- Passengers in 1st class had higher survival.
- Females had higher survival than males.
- Higher fares were associated with better survival odds.
- Younger passengers (children) survived more than adults.
- Embarked = C passengers survived more compared to S or Q.
